# Keyboard

Everything the viewer does, on one page. Every entry is also in the menus.
On macOS, read ++ctrl++ as ++cmd++.

## Looking

| Keys | What it does |
|---|---|
| left-drag · right-drag · scroll | rotate · pan · zoom |
| ++v++ | switch between the CYLview look and the Houk style |
| ++1++ ++2++ ++3++ | ball & stick · stick · line, for the selection or the whole molecule |
| ++l++ | cycle atom labels: element → element + number → number → off |
| ++shift+a++ | the corner XYZ axis triad |
| ++a++ | align the view: down the bond (2 atoms) or into the plane (3 atoms) |
| ++c++ | rotate about the selected atom |
| ++home++ | re-centre on the molecule |
| ++ctrl+r++ | reset the view |
| ++h++ | hydrogen bonds |
| ++ctrl+t++ | the style editor |

## Selecting, measuring and editing

| Keys | What it does |
|---|---|
| click · click again · ++esc++ | add an atom · remove it · clear the selection |
| *(2–4 atoms selected)* | the distance, angle or dihedral is shown live |
| ++m++ · ++shift+m++ | pin the measurement into the scene · clear the pinned ones |
| ++f++ | grow the selection to the whole connected fragment |
| ++g++ | show or hide the move/rotate handles |
| ++shift++ while dragging a handle | snap to 0.1 Å or 15° |
| ++e++ | set the selected distance, angle or dihedral exactly |
| ++x++ | delete the selected atoms |
| ++b++ | recompute bonds |
| ++ctrl+z++ · ++ctrl+y++ | undo · redo |

## Drawing, spectra and files

| Keys | What it does |
|---|---|
| ++shift+l++ | Lewis structure mode; drag turns it, ++shift++-drag spins it |
| ++i++ | isosurface controls |
| ++s++ | the spectra panel |
| ++space++ | stop a vibration animation |
| ++ctrl+o++ | open |
| ++ctrl+s++ | save as `xyz`, `.gjf`, `.inp`, `.in`, `pdb` or `.mol` |
| ++ctrl+e++ | export the view as an image (PNG or TIFF; SVG or PDF in Lewis mode) |
| ++ctrl+shift+s++ | save the Lewis drawing for ChemDraw (`.cdxml` or `.mol`) |

!!! note "On macOS"
    ++ctrl++ in these tables is ++cmd++ — ++ctrl+t++ is ++cmd+t++, and so on.
    Undo and redo follow each platform's own convention: ++cmd+z++ and
    ++cmd+shift+z++ on macOS, ++ctrl+z++ and ++ctrl+y++ elsewhere.
