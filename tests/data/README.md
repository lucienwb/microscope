# Test data

Parser test fixtures.

- `dvb_*.out/.log/.gjf/.fchk`, `orca_dvb_*.out`, `qchem_dvb_*.out`,
  `water_mp2.log`, `trp.log` are taken from the test suite of the
  [cclib](https://github.com/cclib/cclib) project (BSD-3-Clause license) and
  are used here solely as parser test inputs. We thank the cclib developers
  for maintaining this collection of real program outputs.
- `water.molden` is a hand-written minimal Molden file created for this
  project.
